# Code of conduct

This project exists to get statistics right, and that takes people willing to check each
other's work. Everyone taking part in issues, pull requests and discussions agrees to the
following.

## Expected

- Criticise ideas, code and evidence. Never the person.
- Assume good faith, and back claims with a source, a calculation or a test.
- Welcome questions. Nobody starts out knowing this material.
- Accept being wrong gracefully. Finding an error is the point.

## Not accepted

- Harassment, insults or personal attacks.
- Discriminatory language or jokes of any kind.
- Publishing someone's private information.
- Sustained off-topic disruption.

## Enforcement

The maintainer may edit or remove comments, close or lock threads, and block accounts that
break these rules.

To report a problem, use GitHub's **Report content** option on the comment, or contact the
maintainer through their GitHub profile. Reports are kept private.
